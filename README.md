# 卡片模板工坊
一个在浏览器中使用的卡片与挂件模板制作工具。通过首页选择模板，上传图片、编辑文字、调整配色，即可预览并导出设计。

## 模板介绍

### 仿拍立得卡片
- 支持正面与背面编辑，可同步背景、图标和标题。
- 自定义主图及主图背景，支持等比缩放、位置、不透明度、适应高度/宽度、居中与重置。
- 调整文字、暗纹、顶部花纹、图标及背景，支持单独隐藏组件。
- 背面图标支持内部、外部分区调色和不透明度设置。
- 导出当前面的彩色 PNG 或白墨层 PNG。

### 自定义透明卡片
- 卡片尺寸为 80 × 120 mm，主图区域保持透明，支持上传透明底图片。
- 编辑主图、右下角图标、三处文字和背景渐变。
- 内置 15 款图标，支持内部、外部分区调色与不透明度设置；也可上传自定义单色图标。
- 图片支持等比缩放、位置调整、适应高度/宽度、居中与重置。
- 支持参考线显示，以及 150 / 300 / 600 DPI 的彩色和白墨层 PNG 导出。

### 仿存储卡挂件
- 挂件尺寸为 55 × 75 mm，支持正面与背面编辑。
- 自定义图片、文字、配色与触点设置，背面外形与正面对应翻转。
- 支持参考线和切割线设置。
- 支持 600 DPI 的正面、背面、拼版、切割线图片及白墨层导出。

### 通用功能
- 文字编辑：提供多种可选字体，默认宋体；支持字号、颜色、不透明度，以及选中部分文字加粗、删除线和下划线。
- 预览操作：适应屏幕、缩放、放大后拖拽与滚动，以及整个编辑器全屏显示。预览缩放不影响导出尺寸。
- 撤回与重做：支持工具栏按钮及 Ctrl+Z / Ctrl+Y 快捷键。
- 项目管理：通过标题栏的“项目”按钮保存、打开项目及导出图片；首页导入项目可自动识别并打开对应模板。
- 白墨层导出：可分别勾选隐藏对应组件，按最终合成结果提取完全不透明的像素，输出白色与透明组成的 PNG 蒙版。

### 使用方式
1. 打开首页 index.html，选择一个模板。
2. 上传图片并调整文字、图标、配色和位置。
3. 点击“项目”，保存项目文件，或导出制作完成的 PNG 图片。
图片与编辑内容在浏览器本地处理。建议在关闭页面前保存项目，便于之后继续编辑。

### 部署与文件结构
本工具为静态网页，无需安装依赖或构建。将完整文件目录上传至静态网页托管服务即可使用；本地预览建议通过网页服务器打开。
文件	用途
index.html	首页目录与公共工具栏
assets/studio.css	公共界面样式
assets/studio.js	导航、项目导入和公共工具栏逻辑
templates/polaroid.html	仿拍立得卡片模板
templates/card.html	自定义透明卡片模板
templates/storage.html	仿存储卡挂件模板
